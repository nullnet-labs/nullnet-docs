# Fullstack Bootstrap

These pages detail the steps I took to create this application from the ground up. It's meant to be a guide to create another application using the same technology stack (Spring Boot, Next.JS, AWS).

It does not detail this particular application's business logic, architecture decisions, or things that are already documented through its code. As I'm recording these steps through my own build of the application, any mistakes I make or backtracks I perform will be redacted from this area of the documentation. This means the documents here will only include the steps where everything works.
